
# 📝 To-Do App

A simple and interactive **To-Do List Web App** built using **HTML, CSS, and JavaScript**. This app helps you **organize tasks** by letting you **add**, **track**, and **manage** them in separate sections for **Pending** and **Completed** tasks.

---

## ✨ Features
- ✅ Add new tasks instantly
- 📌 Separate sections for **Pending Tasks** and **Completed Tasks**
- 🖱️ Simple, clean, and responsive UI
- 🔄 Real-time updates with JavaScript

---

## 🛠️ Tech Stack
- **HTML** – For structuring the app
- **CSS** – For styling and layout
- **JavaScript** – For dynamic functionality

---

## 📂 Project Structure
```
├── index.html   # Main HTML file
├── index.css    # Styles for the app
└── index.js     # JavaScript logic for task handling
```
